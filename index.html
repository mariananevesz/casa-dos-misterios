Atalhos de teclado

  • Alt + A — abrir acessibilidade
  • Alt + R — repetir instrução
  • Esc — fechar menu ou janela aberta
  • Tab — navegar entre elementos
  • Enter / Espaço — selecionar / confirmar
  • Delete — remover bloco selecionado
  • V / F — Verdadeiro / Falso (Cozinha)

Como jogar

  • Sala — Monte sequências de blocos para guiar o personagem até a estrela.
  • Quarto — Encontre os erros na rotina e reconstrua a ordem correta.
  • Cozinha — Julgue cada frase: Verdadeiro ou Falso?
  • Despensa — Organize os itens por tamanho, cor ou categoria.

Complete cada cômodo para desbloquear o próximo. Quanto menos erros, mais pontos!
